GitLab CI Integration
Add CryptoGuard to your Android project pipeline
Step 1 — Add job to .gitlab-ci.yml GITLAB CI 
cryptoguard:
  stage: test
  image: python:3.12-slim
  variables:
    CRYPTOGUARD_URL: "http://your-cryptoguard-server:8080"
  script:
    - pip install cryptoguard-cli  # or mount as volume
    - cryptoguard analyze --dir src/ --severity CRITICAL --output results.json
    - |
      curl -s -X POST $CRYPTOGUARD_URL/api/results \
        -H "Content-Type: application/json" \
        -d "{
          \"scan_id\": \"$CI_PIPELINE_ID\",
          \"filename\": \"$CI_PROJECT_NAME\",
          \"findings\": $(cat results.json),
          \"gitlab_project\": \"$CI_PROJECT_NAME\",
          \"gitlab_branch\": \"$CI_COMMIT_BRANCH\",
          \"gitlab_commit\": \"$CI_COMMIT_SHORT_SHA\"
        }"
  artifacts:
    reports:
      sast: results.json
    paths:
      - results.json
    expire_in: 30 days
  allow_failure: false  # fails pipeline on CRITICAL findings
Step 2 — Run with Docker
# Build and run CryptoGuard
docker build -t cryptoguard .
docker run -d \
  --gpus all \
  -p 8080:8080 \
  --name cryptoguard \
  cryptoguard

# Or without GPU (slower inference)
docker run -d \
  -p 8080:8080 \
  --name cryptoguard \
  cryptoguard
Step 3 — How it works

1. Developer pushes code → GitLab pipeline triggers

2. CryptoGuard job runs cryptoguard analyze on the source directory

3. If CRITICAL findings exist → pipeline fails, merge blocked

4. Results POST to this dashboard automatically

5. Security analyst reviews findings here, approves or dismisses


The dashboard receives results from any source — manual uploads, CI/CD pipelines, or the REST API. All findings are stored and searchable.
